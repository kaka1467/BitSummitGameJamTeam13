# 🎮 BitSummit Game Jam — Team Friday The 13th

> **「深夜、親にバレずにゲームをやりきれ！」**

## ゲーム概要

子供部屋でこっそり深夜ゲームをプレイするステルスゲーム。  
親が廊下を歩き回り、ドアを覗いてくる。バレたらゲームオーバー。  
枕の下にコントローラーを隠し、寝たふりでやり過ごせ！

## 特徴

- 🚪 **親の接近システム** — 足音・廊下の電気など予兆を察知してリアクションを起こせ
- 🛏 **枕センサー** — 実際の枕を使った物理コントローラー対応（Arduino連携）
- 📊 **疑惑ゲージ** — 行動が怪しいほどゲージが溜まり、親の動きが激しくなる
- 📷 **カメラ切り替え** — 子供部屋視点と廊下視点のダイナミックな切り替え
